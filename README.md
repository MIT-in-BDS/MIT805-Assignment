# MIT 805 Big Data Project – Cosmopedia Dataset

## Overview

This repository contains our MIT 805 Big Data Project for 2026.

The project investigates the Cosmopedia dataset using PySpark for large-scale data processing and exploratory data analysis (EDA).

The main objectives are to:

- Collect and describe a large publicly available dataset.
- Perform Exploratory Data Analysis (EDA).
- Analyse the dataset using the 7 Vs of Big Data.
- Demonstrate large-scale data processing using PySpark.
- Implement MapReduce-style processing using Spark transformations, grouping/shuffling, and aggregations.
- Visualise important findings.
- Evaluate the business and/or societal value and limitations of the dataset.

---

## Dataset

### Cosmopedia

The dataset used in this project is Cosmopedia, a large-scale collection of synthetic educational content.

**Dataset source:**

https://huggingface.co/datasets/HuggingFaceTB/cosmopedia

The project uses the `web_samples_v1` portion of the Cosmopedia dataset.

The dataset is stored in **Parquet** format.

### Dataset Sizes

| Dataset | Size |
|---|---:|
| Raw public dataset | ~38.98 GB download size |
| Working dataset | ≥12 GB |
| Processing dataset | ≥3 GB |

The raw, working, and processing dataset sizes are reported separately in accordance with the MIT 805 project requirements.
